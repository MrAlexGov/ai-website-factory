# Рабочий процесс AI Website Factory

## Жизненный цикл задачи

1. **Бриф** — цель сайта, аудитория, предложение, география, ограничения и критерии успеха.
2. **Исследование** — конкуренты, поисковый интент, референсы и факты, требующие проверки.
3. **Структура** — карта страниц, секции, пользовательские сценарии и CTA.
4. **Контент и дизайн** — тексты, визуальная система, адаптивные состояния и компоненты.
5. **Реализация** — код, интеграции, формы, аналитика и SEO-техническая база.
6. **Проверка** — сборка, ссылки, формы, доступность, responsive и базовая производительность.
7. **Передача/публикация** — инструкции запуска, переменные окружения и чек-лист релиза.

## Правила репозитория

- Работать только в `MrAlexGov/ai-website-factory`, пока пользователь явно не разрешит другое.
- Не перезаписывать файлы вслепую: сначала получить актуальную версию.
- Не коммитить секреты и реальные значения ключей API.
- Для крупных или рискованных изменений предпочитать отдельную ветку и Pull Request.
- После каждого этапа сообщать, какие файлы изменены и что проверено.

## Стандарт новой задачи

Для каждого сайта рекомендуется создать отдельную папку в `projects/<project-slug>/` и хранить там:
- `BRIEF.md` — бриф и ограничения;
- `SITEMAP.md` — структуру страниц;
- `DESIGN.md` — дизайн-систему и визуальные решения;
- `CONTENT.md` — контент и тексты;
- исходный код сайта и инструкции запуска.
