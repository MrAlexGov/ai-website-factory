# AI Website Factory

Рабочее пространство для проектирования, сборки и сопровождения сайтов с помощью AI-агентов.

## Цели

- Хранить исходники сайтов, компоненты, шаблоны и документацию в одном приватном репозитории.
- Повторно использовать проверенные блоки, дизайн-системы и сценарии сборки.
- Автоматизировать рутинные этапы: от структуры проекта и контента до проверки качества и публикации.
- Фиксировать изменения понятными коммитами.

## Принципы работы

1. Изменения вносятся только в этот репозиторий, если пользователь явно не разрешил иное.
2. Перед изменением существующего файла нужно прочитать его текущее содержимое.
3. Новые задачи оформляются в отдельных папках или ветках, когда это уместно.
4. Секреты, токены, пароли и приватные ключи не добавляются в Git.
5. Важные решения и инструкции документируются рядом с кодом.
