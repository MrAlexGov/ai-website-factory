# AI Website Factory

Рабочее пространство для проектирования, сборки и сопровождения сайтов с помощью AI-агентов.

## Цели

- Хранить исходники сайтов, компоненты, шаблоны и документацию в одном репозитории.
- Повторно использовать проверенные блоки, дизайн-системы и сценарии сборки.
- Автоматизировать путь от брифа до проверки качества и публикации.
- Разделять генерацию/сборку сайта и его размещение на хостинге.

## Принципы работы

1. Изменения вносятся только в этот репозиторий, если пользователь явно не разрешил иное.
2. Перед изменением существующего файла нужно прочитать его текущее содержимое.
3. Секреты, токены, пароли и приватные ключи не добавляются в Git.
4. Сборщик не зависит от конкретного хостинга: он производит готовую папку `dist/`.
5. Не выдавать успешную сборку за успешную публикацию.

## Основные разделы

- `projects/` — проекты сайтов и их конфигурации.
- `tools/site_factory/` — Python-инструменты сборки.
- `templates/` — стартовые шаблоны.
- `skills/` — инструкции для AI-этапов.
- `docs/BUILD_SYSTEM.md` — архитектура сборки и план развития.
- `docs/FACTORY_ARCHITECTURE.md` — полный производственный процесс.

## Быстрый запуск

Требуется Python 3.11+.

```bash
python tools/site_factory/build.py --project projects/abu-dhabi-ac
```

Результат: `dist/abu-dhabi-ac/`.
