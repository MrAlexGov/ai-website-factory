# Static site template

Базовая точка для чистых статических сайтов.

## Стек по умолчанию

- HTML5
- CSS3
- vanilla JavaScript
- без обязательного build step

## Ожидаемая структура

```text
site/
├── index.html
├── assets/
│   ├── css/styles.css
│   ├── js/main.js
│   └── images/
└── README.md
```

Для мультиязычного сайта добавлять языковые каталоги, например `ar/` и `en/`, только если соответствующие страницы подготовлены.

## Важно

Это спецификация стартового шаблона, а не готовый сайт. Конкретные секции, контент, формы, интеграции и SEO создаются на основании утверждённого брифа.
