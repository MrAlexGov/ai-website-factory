# Skills

Здесь хранятся инструкции и повторно используемые навыки AI-агента для этапов создания сайтов.

Каждый навык должен описывать:
- назначение и границы применения;
- входные данные;
- пошаговый процесс;
- ожидаемые файлы/результаты;
- критерии проверки;
- ограничения и безопасную работу с секретами.
