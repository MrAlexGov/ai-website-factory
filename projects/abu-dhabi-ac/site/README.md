# Raha Cooling — Abu Dhabi AC demo

Bilingual static website prototype: Arabic RTL at `/`, English LTR at `/en/`.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server, for example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (Tajawal and Manrope) loaded remotely

No CMS, package manager, bundler or frontend framework is required.

## Demo limitations — must resolve before launch
- Brand name is fictional.
- Phone, WhatsApp, business address, license, prices, warranties and testimonials are intentionally omitted.
- Enquiry form is front-end demonstration only; it does not submit or store data.
- Service areas are preliminary examples, not confirmed operating coverage.
- Arabic copy requires native-speaker review.
- Confirm actual services, equipment brands, service coverage, legal notices and contact channels with the business owner.
- Add production form handling only after selecting and securing a backend or trusted form service. Never put private API credentials in browser code.
