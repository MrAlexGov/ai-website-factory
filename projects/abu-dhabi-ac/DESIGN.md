# Дизайн-направление

## Концепция
Современный premium HVAC-сервис: прохладная светлая основа, глубокий navy, бирюзовый акцент, крупная типографика, много воздуха, выразительный hero с абстрактной иллюстрацией воздушного потока. Не использовать фальшивые фотографии команды/объектов или логотипы брендов.

## Цвета
- Deep navy: #102A43
- Teal: #0D9488
- Ice: #E8F5F5
- Warm white: #F8FAFC
- Body: #334155

## Типографика
- Arabic: Tajawal (Google Fonts) с системным sans-serif fallback.
- English: Manrope с системным sans-serif fallback.

## Компоненты
- sticky header с языковым переключателем;
- hero с двумя CTA;
- service cards;
- process steps;
- area chips;
- FAQ accordion;
- request form;
- footer.

## RTL
Корневой арабский документ: `lang="ar" dir="rtl"`. Использовать logical CSS properties, не полагаться на left/right. Проверять визуальный порядок иконок, стрелок и навигации в RTL и LTR.
